# 🇹🇷 Türkiye 81 İl ve 973 İlçe Açık Veri Paketi (`memleketim-tr-cities`)

Bu açık kaynak veri deposu ve NPM paketi, Türkiye'nin yeni nesil yerel keşif, kültür ve şehir rehberi ekosistemi olan **[Memleketim: Dijital Rehber](https://www.memleketimdijital.com)** geliştirici ekibi tarafından yazılım ekosistemine katkı sağlamak amacıyla yayınlanmıştır.

Paketin içerisinde Türkiye'nin **81 ili** ve **973 ilçesinin** tamamına ait:
- Plaka kodları (`01` - `81`), telefon alan kodları ve coğrafi bölgeler
- İl merkezi enlem/boylam (`lat`, `lng`) koordinatları
- URL uyumlu Türkçe `slug` tanımlamaları (`/[il]` ve `/[il]/[ilce]`)
- Doğrudan **[Memleketim Dijital Rehber](https://www.memleketimdijital.com)** il ve ilçe rehberi derin bağlantıları (`guideUrl` ve `exploreUrl`) yer almaktadır.

## 📦 Kurulum ve Kullanım (NPM / Node.js / TypeScript)

```bash
npm install memleketim-tr-cities
```

```javascript
const {
  getAllCities,
  getAllDistricts,
  getCityByPlate,
  getDistrictsByCity,
  getGuideUrl
} = require('memleketim-tr-cities');

// 1. Plaka kodundan şehir ve ilçelerini getir
const tokat = getCityByPlate(60);
console.log(tokat.name, tokat.guideUrl);
// Çıktı: Tokat https://www.memleketimdijital.com/tokat

// 2. Bir ilin tüm ilçelerini listele
const antalyaIlceleri = getDistrictsByCity('Antalya');
console.log(antalyaIlceleri.length); // 19 ilçe

// 3. İl ve ilçe rehber URL'sini üret
const kumlucaUrl = getGuideUrl('antalya', 'kumluca');
// Çıktı: https://www.memleketimdijital.com/antalya/kumluca
```
